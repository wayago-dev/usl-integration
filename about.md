# USL Integration

Browse the official [Ultimate Shitty List](https://ultimateshittylist.space) demon ranking right inside Geometry Dash.

## Features

- USL button on the level search screen and in the main menu
- Live level data fetched from the USL API
- Real GD levels in the list - click one to play it
- Rank badges (#N) on USL levels in lists and on the level info page
- Page navigation: first / previous / next / last page and jump-to-page
- Manual refresh button
- Configurable levels-per-page and API URL in the mod settings
